IMPERIAL PACK - CATÁLOGO DIGITAL

Arquivos:
- catalogo.html = página pública para enviar aos clientes
- admin.html = painel administrativo para cadastrar/editar produtos

Como testar:
1. Abra admin.html para editar produtos.
2. Abra catalogo.html para visualizar o catálogo.

Observação:
Esta versão salva os dados no localStorage do navegador. Para sincronizar entre celulares e permitir administração online real, é necessário hospedar com banco de dados/backend.
